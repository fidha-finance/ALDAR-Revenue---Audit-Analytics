# Real Estate Revenue & Journal Entry Audit Analytics — Aldar Properties PJSC

## Project Overview

This project demonstrates how Python can be used to support revenue and journal entry audit procedures in a real estate business context.

It uses published financial information from Aldar Properties PJSC and simulated transaction-level data to perform basic audit analytics and identify transactions that may require further investigation.

## Objectives

- Analyse revenue-related financial information.
- Perform journal entry and transaction-level checks.
- Identify unusual transactions using predefined audit rules.
- Summarise potential exceptions through visualisations.
- Demonstrate practical applications of Python in audit analytics.

## Tools Used

- Python
- Google Colab
- Pandas
- Matplotlib
- Excel

## Audit Procedures

The analysis includes:
- Duplicate transaction checks.
- Identification of unusual transaction patterns.
- Review of selected revenue-related exceptions.
- Summary of flagged transactions.
- Visual presentation of audit analytics results.

## Data and Limitations

Published financial information is based on Aldar Properties PJSC's publicly available financial reporting.

**Important:** The transaction-level dataset is simulated for educational purposes. It is not Aldar's actual accounting records, and the flagged items are illustrative indicators for further investigation, not actual audit findings.

This project is a learning-oriented audit analytics prototype. It does not constitute a statutory audit, assurance opinion, or confirmation of IFRS compliance.

## Purpose

This project demonstrates foundational skills in financial data analysis, audit procedures, exception identification, and communicating analytical results.
